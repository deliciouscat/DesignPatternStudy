# 문제

**시나리오:**
주식 시세 앱을 만들고 있습니다. 주식 가격이 변동하면 이를 여러 컴포넌트(차트, 알림 매니저, 포트폴리오, 통계)에 즉시 알려야 합니다. 새로운 옵저버가 동적으로 추가되거나 제거될 수 있으며, 각 옵저버는 독립적으로 동작합니다.

**요구사항:**
1. Subject(주체): `Stock` - 주식 정보 관리
2. Observers(옵저버): `PriceChart`, `NotificationManager`, `Portfolio`, `StatisticsCollector`
3. Stock 클래스:
   - `symbol`: 주식 심볼 (예: "AAPL")
   - `price`: 현재 가격
   - `setPrice(newPrice)`: 가격 업데이트 → 모든 옵저버에 알림
   - `attach(observer)`: 옵저버 등록
   - `detach(observer)`: 옵저버 제거
   - `getObservers()`: 등록된 옵저버 목록 반환
4. 각 옵저버는 `update(stock)` 메서드 구현
   - `PriceChart`: 새로운 가격을 차트에 추가
   - `NotificationManager`: 가격 변동률이 5% 이상이면 알림 발송
   - `Portfolio`: 자신의 포트폴리오에 이 주식이 있다면 현재 자산 재계산
   - `StatisticsCollector`: 가격 통계(최고가, 최저가, 평균) 업데이트

**예시 사용 시나리오:**
```
// 주식 생성
apple = Stock("AAPL", 150.0)

// 옵저버 생성
chart = PriceChart()
notification = NotificationManager()
portfolio = Portfolio("내 포트폴리오")
stats = StatisticsCollector()

// 옵저버 등록
apple.attach(chart)
apple.attach(notification)
apple.attach(portfolio)
apple.attach(stats)

// 가격 업데이트 → 모든 옵저버에 자동 알림
apple.setPrice(155.0)  // 가격이 5% 상승
// → chart가 새 가격 기록
// → notification이 "AAPL 가격이 5.0% 상승했습니다!" 메시지 전송
// → portfolio가 자산 재계산
// → stats가 통계 업데이트

// 특정 옵저버 제거
apple.detach(notification)

// 이제 notification은 알림을 받지 않음
apple.setPrice(160.0)
```

**추가 요구사항:**
- 같은 옵저버를 중복으로 등록할 수 없음
- 옵저버 제거 시 존재하지 않으면 무시
- 옵저버는 업데이트 중에 자신을 제거할 수 없음 (반복 중 컬렉션 수정 방지)
- 옵저버들의 업데이트 순서는 등록 순서대로
