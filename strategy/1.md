# 문제

**시나리오:**
게임의 공격 시스템을 만들고 있습니다. 같은 기본 공격(소드, 보우, 매직)이어도 상황에 따라 다른 방식으로 동작해야 합니다. 예를 들어, 밤에는 데미지 증가, 높은 위치에서는 명중률 증가 등의 전략을 적용해야 합니다. 런타임에 동적으로 전략을 교체할 수 있어야 합니다.

**요구사항:**
1. Context(문맥): `Character` - 공격을 수행하는 캐릭터
2. 기본 공격 방식: `SwordAttack`, `BowAttack`, `MagicAttack`
3. 전략(Strategy):
   - `DayTimeStrategy`: 낮 시간 공격 (기본 데미지)
   - `NightTimeStrategy`: 밤 시간 공격 (데미지 1.5배 증가)
   - `HighGroundStrategy`: 높은 위치에서 공격 (명중률 +30%, 데미지 +20%)
   - `SurroundedStrategy`: 포위된 상황 (데미지 -20%, 방어력 +50%)
   - `RageModeStrategy`: 분노 상태 (데미지 2배, 하지만 명중률 -30%)
4. Character 클래스:
   - `name`: 캐릭터 이름
   - `weapon`: 무기 종류 (Sword, Bow, Magic)
   - `baseDamage`: 기본 데미지
   - `accuracy`: 명중률 (0~100)
   - `attackStrategy`: 현재 적용된 전략
   - `setStrategy(strategy)`: 전략 변경
   - `attack(target)`: 현재 전략을 적용해 공격 실행
5. 각 Strategy는 `executeAttack(character, target)` 메서드 구현

**예시 사용 시나리오:**
```
// 캐릭터 생성
hero = Character("용사", weapon="Sword", baseDamage=20, accuracy=80)

// 기본 공격 (낮 시간 전략)
hero.setStrategy(DayTimeStrategy())
hero.attack(goblin)  // 데미지: 20, 명중률: 80%

// 밤 시간으로 변경 → 전략 변경
hero.setStrategy(NightTimeStrategy())
hero.attack(goblin)  // 데미지: 30 (20 * 1.5), 명중률: 80%

// 높은 위치로 이동 → 전략 변경
hero.setStrategy(HighGroundStrategy())
hero.attack(goblin)  // 데미지: 24 (20 * 1.2), 명중률: 110% (→ 100%로 제한)

// 적군에게 포위됨 → 전략 변경
hero.setStrategy(SurroundedStrategy())
hero.attack(goblin)  // 데미지: 16 (20 * 0.8), 명중률: 80%

// 분노 상태 → 전략 변경
hero.setStrategy(RageModeStrategy())
hero.attack(goblin)  // 데미지: 40 (20 * 2), 명중률: 50% (80 - 30)

// 다시 낮 시간 전략으로 돌아감
hero.setStrategy(DayTimeStrategy())
hero.attack(goblin)  // 데미지: 20, 명중률: 80%
```

**추가 요구사항:**
- 같은 전략이 중복으로 설정되면 무시
- 공격 결과 로깅 (데미지, 명중 여부, 적용된 전략)
- 전략이 명시적으로 설정되지 않으면 기본 전략(DayTimeStrategy) 사용
- 각 전략은 독립적으로 캐릭터의 스탯을 수정하지 않음 (일시적 변경만)
