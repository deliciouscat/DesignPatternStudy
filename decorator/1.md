# 문제

**시나리오:**
카페 주문 시스템을 만들고 있습니다. 기본 음료(커피, 차)가 있고, 사용자가 다양한 추가 옵션(샷 추가, 우유, 휘핑크림 등)을 선택할 수 있습니다. 각 옵션은 기본 음료의 기능을 확장하지만 원본 음료는 수정되지 않아야 합니다.

**요구사항:**
1. 기본 음료: `Coffee`, `Tea`
2. 추가 옵션(Decorator): `ExtraShot`, `Milk`, `WhippedCream`, `Caramel`, `Chocolate`
3. 각 음료와 옵션은 동일한 인터페이스 제공:
   - `getDescription()`: 음료 설명 (예: "에스프레소 + 우유 + 휘핑크림")
   - `getPrice()`: 총 가격 계산 (기본 음료 + 모든 옵션의 합)
   - `getCalories()`: 총 칼로리 계산
4. 옵션들은 자유롭게 조합 가능 (같은 옵션을 여러 번 추가 가능)
5. 원본 음료는 변경되지 않음 (불변성 유지)

**예시 사용 시나리오:**
```
// 기본 커피: 2,500원, 50 kcal
coffee = Coffee()

// 커피 + 샷 추가 + 우유: 4,500원, 150 kcal
coffeeWithMilkAndShot = ExtraShot(Milk(coffee))

// 같은 커피를 여러 번 사용해도 원본은 변경되지 않음
coffeeWithChocolate = Chocolate(coffee)

coffee.getPrice()  // 여전히 2,500원

// 복잡한 조합도 가능
complexCoffee = WhippedCream(Caramel(ExtraShot(Milk(coffee))))
complexCoffee.getPrice()  // 모든 옵션의 가격 합산
```

**추가 요구사항:**
- 옵션 중복 방지 (같은 옵션을 2회 이상 추가할 때 경고)
- 옵션의 순서는 상관없음 (같은 옵션들이라면 가격과 칼로리는 동일)
- 각 옵션은 독립적으로 작동
