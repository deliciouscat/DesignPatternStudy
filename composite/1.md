# 문제

**시나리오:**
그래픽 에디터에서 사용자가 여러 도형을 그룹으로 묶고, 그룹을 다시 그룹으로 묶을 수 있습니다. 각 도형과 그룹은 동일한 방식으로 다뤄야 합니다.

**요구사항:**
1. 기본 도형: `Circle`, `Rectangle`, `Line` 등
2. 도형 그룹: 여러 도형을 묶어 하나의 단위로 처리
3. 중첩 그룹: 그룹 안에 그룹 포함 가능
4. 공통 동작:
   - `render()`: 화면에 그리기
   - `move(x, y)`: 위치 이동
   - `getBounds()`: 경계 영역 계산
   - `scale(factor)`: 크기 조절

**예시 사용 시나리오:**
- 사용자가 원 2개와 사각형 1개를 선택해 "눈" 그룹 생성
- "눈" 그룹 2개와 "코" 그룹 1개를 묶어 "얼굴" 그룹 생성
- "얼굴" 그룹 전체를 이동/확대/축소 가능

Component: Shape 클래스

# 평가

현재 코드는 기본 상속 구조는 있지만, Composite 패턴의 핵심인 그룹(복합 객체)이 빠져 있습니다.

## 현재 코드의 문제점

1. `Group` 클래스가 없음 — Composite 패턴의 핵심인 복합 객체가 없습니다.
2. `Circle` 클래스가 중복 정의됨 (55줄과 67줄).
3. `getBounds()` 메서드가 요구사항에 있지만 구현되지 않음.
4. 개별 도형과 그룹을 동일한 인터페이스로 다루는 구조가 없음.

## Composite 패턴의 핵심 구조

Composite 패턴은 다음 3가지 요소로 구성됩니다:

1. Component (공통 인터페이스): `Shape` 클래스
2. Leaf (개별 객체): `Circle`, `Rectangle`, `Line`
3. Composite (복합 객체): `Group` 클래스 — 자식들을 관리하며 동일한 인터페이스를 구현

## 수정 방향

`Group` 클래스를 추가하고, 다음과 같이 동작하도록 설계하세요:

- `Group`은 `Shape`를 상속받아 동일한 인터페이스(`render()`, `move()`, `scale()`, `getBounds()`)를 구현
- `Group`은 자식 `Shape` 객체들의 리스트를 관리
- `Group`의 `render()`는 모든 자식을 순회하며 `render()` 호출
- `Group`의 `move()`는 모든 자식을 이동
- `Group`의 `getBounds()`는 모든 자식의 경계를 합쳐서 계산

```
Class Shape (Abstract):
    Property{
        location: dict{
            x: float,
            y: float,
            z: float
        }
        size: float
        lineColor: hex
    }
    function{
        @abstract
        def render():
            ... override in subclass ...

        @abstract
        def move(dx, dy):
            ... override in subclass ...

        @abstract
        def scale(factor):
            ... override in subclass ...

        @abstract
        def get_bounds():
            ... override in subclass ...
    }

Class Circle(Shape):
    Property{
        radius: float
        fillColor: hex
    }

    function{
        @override
        def render():
            ... rendering process for circle ...
            return log(f"Circle rendered at {location}")

        @override
        def move(dx, dy):
            location['x'] += dx
            location['y'] += dy
            render()

        @override
        def scale(factor):
            radius *= factor
            render()

        @override
        def get_bounds():
            return {
                x_min: location['x'] - radius,
                y_min: location['y'] - radius,
                x_max: location['x'] + radius,
                y_max: location['y'] + radius
            }
    }

Class Rectangle(Shape):
    Property{
        width: float
        height: float
        fillColor: hex
    }

    function{
        @override
        def render():
            ... rendering process for rectangle ...
            return log(f"Rectangle rendered at {location}")

        @override
        def move(dx, dy):
            location['x'] += dx
            location['y'] += dy
            render()

        @override
        def scale(factor):
            width *= factor
            height *= factor
            render()

        @override
        def get_bounds():
            return {
                x_min: location['x'],
                y_min: location['y'],
                x_max: location['x'] + width,
                y_max: location['y'] + height
            }
    }

Class Line(Shape):
    Property{
        end_location: dict{
            x: float,
            y: float,
            z: float
        }
        lineColor: hex
    }

    function{
        @override
        def render():
            ... rendering process for line ...
            return log(f"Line from {location} to {end_location}")

        @override
        def move(dx, dy):
            location['x'] += dx
            location['y'] += dy
            end_location['x'] += dx
            end_location['y'] += dy
            render()

        @override
        def scale(factor):
            dx = end_location['x'] - location['x']
            dy = end_location['y'] - location['y']
            end_location['x'] = location['x'] + dx * factor
            end_location['y'] = location['y'] + dy * factor
            render()

        @override
        def get_bounds():
            return {
                x_min: min(location['x'], end_location['x']),
                y_min: min(location['y'], end_location['y']),
                x_max: max(location['x'], end_location['x']),
                y_max: max(location['y'], end_location['y'])
            }
    }

Class Group(Shape):
    Property{
        children: List<Shape>
        name: string
    }

    function{
        def __init__(name):
            children = []
            self.name = name

        def add_child(shape: Shape):
            children.append(shape)
            log(f"Added shape to group '{name}'")

        def remove_child(shape: Shape):
            if shape in children:
                children.remove(shape)
                log(f"Removed shape from group '{name}'")

        @override
        def render():
            result = f"Group '{name}' rendering:"
            for child in children:
                result += "\n  " + child.render()
            return result

        @override
        def move(dx, dy):
            log(f"Group '{name}' moving by ({dx}, {dy})")
            for child in children:
                child.move(dx, dy)
            location['x'] += dx
            location['y'] += dy

        @override
        def scale(factor):
            log(f"Group '{name}' scaling by {factor}")
            for child in children:
                child.scale(factor)
            size *= factor

        @override
        def get_bounds():
            if children is empty:
                return { x_min: 0, y_min: 0, x_max: 0, y_max: 0 }
            
            bounds_list = []
            for child in children:
                bounds_list.append(child.get_bounds())
            
            return {
                x_min: min(all x_min in bounds_list),
                y_min: min(all y_min in bounds_list),
                x_max: max(all x_max in bounds_list),
                y_max: max(all y_max in bounds_list)
            }
    }
```

# 신경써야 됐던 점

`Shape` 클래스는 추상적으로만 정의해도 된다는 점. 지나치게 구체적으로 정의하려 들려고 했음.

Composite 클래스인 `Group`의 설계: `children`을 정의하고 다른 Shape 객체들을 포함하는 구조.
