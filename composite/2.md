# 문제

**시나리오:**
파일 시스템 탐색기를 만들고 있습니다. 사용자가 파일과 폴더를 트리 구조로 탐색할 수 있어야 하며, 폴더 안에는 다른 폴더와 파일이 모두 포함될 수 있습니다. 또한 전체 저장 공간을 계산하거나 폴더 내 모든 파일을 검색할 수 있어야 합니다.

**요구사항:**
1. 기본 요소: `File` (개별 파일), `Folder` (폴더)
2. 폴더 안에 폴더와 파일을 모두 포함 가능 (중첩 구조)
3. 공통 동작:
   - `getName()`: 이름 반환
   - `getSize()`: 크기 반환 (파일: 파일 크기, 폴더: 내부 모든 파일의 합계)
   - `display()`: 트리 형식으로 계층 구조 출력
   - `search(keyword)`: 이름에 키워드를 포함하는 모든 항목 찾기
   - `delete()`: 파일 또는 폴더 삭제 (폴더는 내용물까지 삭제)

**예시 사용 시나리오:**
```

├─ 📁 DesignPatterns
│  ├─ 📄 composite.py (2.5 KB)
│  ├─ 📄 observer.py (1.8 KB)
│  └─ 📁 tests
│     ├─ 📄 test_composite.py (3.2 KB)
│     └─ 📄 test_observer.py (2.1 KB)
├─ 📁 WebApp
│  ├─ 📄 app.js (15.3 KB)
│  └─ 📁 components
│     ├─ 📄 Button.jsx (0.9 KB)
│     └─ 📄 Modal.jsx (2.5 KB)
└─ 📄 README.md (4.2 KB)

// 사용 예시:
Projects.getSize()  // 전체 크기 계산
Projects.search("composite")  // "composite"를 포함하는 모든 항목 찾기
DesignPatterns.display()  // DesignPatterns 폴더 안의 계층 구조 출력
```

**추가 요구사항:**
- 중복된 이름을 가진 파일/폴더가 같은 폴더 내에 존재할 수 없음
- 같은 객체를 여러 곳에 추가할 수 없음 (복사 관계 아님)
- 폴더 크기는 지연 계산 (lazy evaluation) - 필요할 때만 계산

# 평가

좋은 문제와 해답을 작성하셨네요! Composite Pattern 이해도를 체계적으로 평가해 드리겠습니다.

## 평가

### ✅ **잘한 점**

1. **올바른 구조 설계**
   - `Component` 추상 클래스를 통해 공통 인터페이스 정의
   - `File`과 `Directory`의 상속 관계 명확함
   - 재귀적 구조를 제대로 표현 (`children: List[Component]`)

2. **핵심 메서드 구현**
   - `getSize()`의 재귀적 접근 방식이 Composite Pattern의 정수
   - `search()` 메서드도 재귀적으로 올바르게 설계됨
   - 추상 메서드 사용으로 오버라이딩 강제

3. **요구사항 반영**
   - 중복 이름 체크 로직 포함
   - 지연 계산(lazy evaluation) 개념 인식

### ⚠️ **개선할 점**

1. **`children.extend(file.copy)` 문제**
   - ❌ `file.copy` 표현이 모호함 (Python에서 `.copy()`는 메서드)
   - ❌ 가장 중요한 요구사항 "같은 객체를 여러 곳에 추가할 수 없음"을 **복사로 해결하려는 것**은 잘못된 접근
   - ✅ **올바른 접근**: 객체 참조를 직접 추가하되, 이미 다른 곳에 속한 객체는 거절해야 함
   ```python
   # 개선안
   if file.parent is not None:  # 이미 다른 폴더에 속함
       raise ErrorMessage("이미 다른 곳에 속한 객체")
   file.parent = self
   self.children.append(file)
   ```

2. **누락된 필수 메서드**
   - `getName()` 구현 누락
   - `display()` 구현 누락 (트리 형식 출력이 중요)
   - `delete()` 구현 누락

3. **`leafs` 프로퍼티의 모호성**
   ```python
   leafs: List[File]  # 이게 필요한가?
   ```
   - Directory도 leaf가 될 수 있으므로 불명확함
   - 재귀 탐색으로 충분하므로 제거 권장

4. **지연 계산(Lazy Evaluation) 미흡**
   - 선언만 했고 구현이 모호함
   - 캐싱 메커니즘이 필요 (파일 추가/삭제 시 캐시 무효화)

### 📋 **수정 예시**

```python
Class Component:
   Property{
      name: str
   }
   
   Function{
      @abstract def getSize() -> number
      @abstract def display(indent: int = 0)
      @abstract def search(keyword: str) -> List[Component]
      @abstract def delete()
   }

Class File(Component):
   Property{
      extension: str,
      size: number
   }
   
   Function{
      def getSize():
         return self.size
      
      def display(indent=0):
         print("  " * indent + "📄 " + self.name)
      
      def search(keyword):
         return [self] if keyword in self.name else []
      
      def delete():
         self.parent.children.remove(self)
   }

Class Directory(Component):
   Property{
      children: List[Component],
      parent: Component = None,
      _sizeCache: number = None
   }
   
   Function{
      def add(component):
         # 1. 중복 이름 체크
         if component.name in [c.name for c in self.children]:
            raise DuplicateNameError()
         
         # 2. 이미 다른 곳에 속해있으면 거절 ⭐
         if component.parent is not None and component.parent != self:
            raise AlreadyOwnedError()
         
         component.parent = self
         self.children.append(component)
         self._invalidateCache()
      
      def getSize():
         if self._sizeCache is None:
            self._sizeCache = sum(c.getSize() for c in self.children)
         return self._sizeCache
      
      def _invalidateCache():
         self._sizeCache = None
         if self.parent:
            self.parent._invalidateCache()
      
      def display(indent=0):
         print("  " * indent + "📁 " + self.name)
         for child in self.children:
            child.display(indent + 1)
      
      def search(keyword):
         result = []
         if keyword in self.name:
            result.append(self)
         for child in self.children:
            result.extend(child.search(keyword))
         return result
   }
```
