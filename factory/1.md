# 문제

**시나리오:**
게임에서 다양한 종류의 캐릭터를 생성해야 합니다. 캐릭터 종류(전사, 마법사, 궁수)에 따라 생성 방식이 완전히 다르며, 생성 과정이 복잡합니다. 클라이언트는 복잡한 생성 로직을 알지 않고 원하는 캐릭터만 요청해야 합니다.

**요구사항:**
1. 캐릭터 종류: `Warrior`, `Mage`, `Archer`
2. 각 캐릭터는 다음 속성을 가짐:
   - `name`: 캐릭터 이름
   - `stats`: 능력치 (strength, intelligence, dexterity, health)
   - `equipment`: 장비 (weapon, armor, accessory)
   - `skills`: 스킬 리스트
3. 생성 방식:
   - `Warrior`: 높은 strength, 기본 방어구, 근접 무기, 전사 스킬
   - `Mage`: 높은 intelligence, 가벼운 방어구, 마법봉, 마법 스킬
   - `Archer`: 높은 dexterity, 가벼운 방어구, 활, 원거리 스킬
4. Factory는 문자열로 요청받아 적절한 캐릭터 생성
5. 같은 종류의 캐릭터를 여러 개 생성 가능 (초기 설정은 같지만 각각 독립적)

**예시 사용 시나리오:**
```
characterFactory = CharacterFactory()

// 전사 생성
warrior1 = characterFactory.createCharacter("warrior", "용사 아서")
warrior1.getStats()  // {strength: 18, intelligence: 8, dexterity: 10, health: 100}
warrior1.getEquipment()  // {weapon: "거대 검", armor: "철 갑옷", ...}

// 마법사 생성
mage1 = characterFactory.createCharacter("mage", "마법사 머린")
mage1.getStats()  // {strength: 8, intelligence: 18, dexterity: 12, health: 60}
mage1.getEquipment()  // {weapon: "마법봉", armor: "로브", ...}

// 궁수 생성
archer1 = characterFactory.createCharacter("archer", "궁수 로빈")

// 같은 종류의 캐릭터 여러 개 생성
warrior2 = characterFactory.createCharacter("warrior", "검사 레온")

// 존재하지 않는 종류 요청 시 에러
unknownCharacter = characterFactory.createCharacter("dragon", "드래곤")  // Error!
```

**추가 요구사항:**
- 캐릭터 종류가 올바르지 않으면 예외 발생
- Factory는 단 하나만 존재 (Singleton 패턴 고려)
- 생성된 각 캐릭터는 독립적인 인스턴스
- 캐릭터 정보 출력 메서드 제공
